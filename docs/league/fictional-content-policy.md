# Fictional Content Policy

## Purpose

Gridiron GM is intended to be an original football-management game. Development should not depend on unlicensed professional or collegiate sports branding, player likenesses, proprietary ratings, or copied statistical databases.

## Default Content Rule

Use original content for:

- league name and branding
- team nicknames
- team logos and uniform designs
- team color systems where a combination could imply an existing club
- stadium names and branding
- coaches and staff
- player names and biographies
- league history

Real city and geographic names may be used when appropriate, subject to review for the overall branding context.

## Do Not Import by Default

Do not build the core game around:

- NFL or NCAA logos
- official team marks
- copied uniform designs
- official stadium marks or sponsored stadium branding
- real player likenesses
- proprietary video-game ratings
- scraped commercial sports datasets whose license does not permit reuse

## Development Data

Synthetic test data is preferred. Generated data should be deterministic when possible so tests remain reproducible.

## Modding Boundary

A future modding/import system may allow users to supply their own league data. If implemented, the base repository and distributed game should remain independent of third-party licensed content.

## Review Principle

When a fictional team or asset resembles an existing sports property strongly enough that a reasonable user might assume affiliation, redesign it before distribution.
